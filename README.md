## 💻 Como Executar Localmente

```bash
# Clonar repositório
git clone https://github.com/PabloFront20/dashboard-interativo-python-alura.git

# Entrar na pasta
cd dashboard-interativo-python-alura

# Criar ambiente virtual (opcional)
python -m venv venv
# Ativar:
# macOS / Linux:
source venv/bin/activate
# Windows:
venv\Scripts\activate

# Instalar dependências
pip install -r requirements.txt

# Iniciar o app
streamlit run app.py
http://localhost:8501
